Discord Bot Development Guide 2025

A complete guide to building feature-rich Discord bots with Python and discord.js, from setup to deployment.

Getting Started

Discord bots are applications that interact with users on Discord servers. In 2025, there are two main approaches: Python with discord.py and JavaScript with discord.js. Both are excellent choices.

1. Setting Up Your Bot

First, create a bot application on the Discord Developer Portal and invite it to your server:

# Python (discord.py)
pip install discord.py

import discord
from discord.ext import commands

bot = commands.Bot(command_prefix='!', intents=discord.Intents.all())

@bot.event
async def on_ready():
    print(f'{bot.user} has logged in!')

bot.run('YOUR_BOT_TOKEN')

2. Slash Commands

Slash commands are the modern way to interact with bots. They provide autocomplete, descriptions, and a better UX:

@bot.tree.command(name="hello", description="Say hello!")
async def hello(interaction: discord.Interaction):
    await interaction.response.send_message(
        f"Hello, {interaction.user.mention}! 👋"
    )

# Sync commands on ready
@bot.event
async def on_ready():
    await bot.tree.sync()
    print('Commands synced!')

3. Moderation System

Every good bot needs moderation tools. Here's a basic kick command with permission checks:

@bot.tree.command(name="kick", description="Kick a member")
@discord.app_commands.describe(member="The member to kick", reason="Reason")
async def kick(interaction: discord.Interaction, member: discord.Member, reason: str = "No reason"):
    if not interaction.user.guild_permissions.kick_members:
        await interaction.response.send_message("No permission!", ephemeral=True)
        return

    await member.kick(reason=reason)
    await interaction.response.send_message(f"Kicked {member.mention}: {reason}")

4. Database Integration

For persistent data like user levels, economies, or custom settings, use a database:

import sqlite3

db = sqlite3.connect('bot_data.db')
cursor = db.cursor()

cursor.execute('''
    CREATE TABLE IF NOT EXISTS levels (
        user_id INTEGER PRIMARY KEY,
        xp INTEGER DEFAULT 0,
        level INTEGER DEFAULT 1
    )
''')
db.commit()

5. Deployment

Deploy your bot 24/7 using services like Railway, Render, or a VPS. Always use environment variables for your bot token:

# Use environment variables - NEVER hardcode tokens
import os
bot.run(os.getenv('DISCORD_TOKEN'))
Security tip: Never commit your bot token to Git. Always use .env files and add them to .gitignore.

Conclusion

Discord bot development is a rewarding skill. Start with the basics, master slash commands, and gradually add features like databases and moderation. The Discord developer community is incredibly supportive!
